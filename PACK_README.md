# Setup

1. Create your Android project (or an empty Git repository).
2. Copy everything in this pack into the project root, including the hidden `.agents` folder.
3. Open the project root as the workspace in Antigravity.
4. In Antigravity's customization settings, check that the rules in `.agents/rules` are active. Set the activation mode you prefer, for example always on for the rules. Confirm current options in Antigravity's documentation.
5. Start with: "Read PROJECT_BRIEF.md and AGENTS.md, then run /plan-feature for milestone M1."
6. Delete this file after setup.

Expected layout:
AGENTS.md, PROJECT_BRIEF.md, docs/ (7 files), .agents/rules (7 files), .agents/workflows (6 files), .agents/skills (5 folders with SKILL.md).
